# prose
Generate beautiful PDFs.

prose underneath uses the [piudf](https://github.com/soypat/piudf) PDF decoding/encoding library.
## Generate examples
```
go run ./examples/prose-docs
go test ./examples/cv
go test ./examples/prospectus
```
